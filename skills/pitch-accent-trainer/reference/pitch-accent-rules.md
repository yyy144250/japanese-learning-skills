# Japanese Pitch Accent Quick Reference

## The 4 Accent Types (for Standard Tokyo Japanese)

### Type 0: 平板型 (Heiban / Flat)
- Pattern: L-H-H-H-H...
- First mora is low, rest stay high (including particles)
- Example: さくら (L-H-H) + が(H)
- Most common type (~50% of words)

### Type 1: 頭高型 (Atamadaka / Head-high)
- Pattern: H-L-L-L...
- First mora is high, everything drops after
- Example: あめ (H-L) + が(L) = rain
- Particles attach LOW

### Type 2+: 中高型 (Nakadaka / Middle-high)
- Pattern: L-H...(drop)...L-L
- Drops after the Nth mora (N = accent number)
- Example: おとこ[3] = L-H-L + が(L) = man (drops after 3rd)

### Type N (=last mora): 尾高型 (Odaka / Tail-high)
- Pattern: L-H-H-H (sounds flat in isolation, drops on particle)
- Example: おとうと[4] = L-H-H-H + が(L) = younger brother
- Indistinguishable from 平板 in isolation!

## Common Rules

### Verbs (辞書形)
- 2-mora verbs: usually Type 0 (flat) or Type 2
  - 見る[1], 来る[1], する[0], 食べる[2], 出る[1]
- ます-form: usually accent on ま
  - たべます (L-H-H-L), のみます (L-H-H-L)

### い-Adjectives
- 3-mora: usually Type 2 (L-H-L)
  - あかい(L-H-L), あおい(L-H-L)
- Exception: おおきい(L-H-H-L), ちいさい(L-H-H-L)

### な-Adjectives
- Often flat (Type 0): きれい(L-H-H), しずか(L-H-H)

### Compound Words
- Usually: first word's accent is maintained
- Long compounds: accent often falls on the second element

### Loanwords (カタカナ)
- General rule: accent on the 3rd mora from the end
  - コンピューター → accent on ュー (3rd from end)
  - テレビ → accent on レ (3rd from end) → L-H-L
- 3-mora words: accent on first → H-L-L (テスト)
- 2-mora words: accent on first → H-L (メモ)
- Exceptions are common!

### Numbers
- 1-10: Mixed, must memorize
- いち(H-L), に(H), さん(H-L), し/よん(H-L/L-H-L)

## Sentence Intonation Rules

1. Each word has its own accent pattern
2. Between words, pitch resets slightly
3. Question sentences: final particle rises か↗
4. Emphasis: pitch range expands on focused word
5. Continuation (、): slight rise before pause

## Practice Strategy

1. Start with minimal pairs (箸/橋, 雨/飴)
2. Learn rules for your most-used word categories
3. Listen for the "drop" — train your ear to hear where pitch falls
4. Use OJAD (Online Japanese Accent Dictionary) to verify: http://www.gavo.t.u-tokyo.ac.jp/ojad/
5. Record yourself and compare with native audio
