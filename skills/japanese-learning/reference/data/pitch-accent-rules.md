# 日语音高重音规则参考（东京方言）

## 基本规则

1. **第 1 拍与第 2 拍必不同高**
   - 第 1 拍高 → 头高型或中高型
   - 第 1 拍低 → 平板型或尾高型

2. **下降后不再上升**（同一个词内）
   - HL 之后不会再出现 H

3. **只有一个下降点**（アクセント核）
   - 下降点的位置决定了型

## 四种类型

### 平板型（へいばんがた）— 型号 0
- 模式：L-H-H-H...（助词也高）
- 特征：没有下降点
- 例：さくら LHH、はな LH

### 头高型（あたまだかがた）— 型号 1
- 模式：H-L-L-L...（助词也低）
- 特征：第 1 拍最高，之后一直低
- 例：いのち HLL、あめ HL（雨）

### 中高型（なかだかがた）— 型号 2~n-1
- 模式：L-H...H-L-L...（助词低）
- 特征：中间某拍后下降
- 例：おとこ LHL（型号2）、おとうと LHHHL（型号3）

### 尾高型（おだかがた）— 型号 n
- 模式：L-H-H...H（助词低）
- 特征：最后一拍高，但助词变低
- 例：はし LH（桥，助词が→低）、いもうと LHHH（助词が→低）

## 规律性模式

### 动词
- 大多数动词为平板型(0)或头高型(-2，倒数第二拍后降)
- ます形：通常在「ま」之前有下降点

### い形容词
- 多为中高型，下降点常在倒数第 2-3 拍
- 例：たか↓い（高い）、おもしろ↓い（面白い）

### 复合词
- 前词 + 后词 → 下降点通常在后词第一拍
- 例：日本(にほん) + 語(ご) → にほ↓んご

### 外来词
- 3拍：多为平板型（コップ LHH）
- 4拍+：多为中高型，下降在倒数第3拍（コンピュ↓ーター）

## 助词的声调行为

| 助词 | 前接平板 | 前接有核 |
|------|----------|----------|
| が | H（保持高） | L（下降后） |
| を | H | L |
| に | H | L |
| は | H | L |
| も | H | L |

## 学习建议

1. 先掌握平板型 vs 头高型的区分（最常见）
2. 记住「同音异义词」的音高对立（箸/橋/端）
3. 动词/形容词按规律记，名词逐个记
4. 用 OJAD（オンライン日本語アクセント辞書）验证
