# 语法点速查表（按 JLPT 等级）

## N5 核心语法

| 语法 | 接续 | 含义 | 例 |
|------|------|------|---|
| 〜は〜です | 名+は+名+です | A是B | 私は学生です |
| 〜があります/います | 名+が+ある/いる | 存在 | 猫がいます |
| 〜を〜ます | 名+を+動 | 动作对象 | 本を読みます |
| 〜に行きます | 場所+に+行く | 去某处 | 学校に行きます |
| 〜てください | 動て形+ください | 请做... | 見てください |
| 〜ている | 動て形+いる | 正在/状态 | 食べている |
| 〜たい | 動ます形+たい | 想做... | 行きたい |
| 〜ないでください | 動ない形+でください | 请不要 | 触らないでください |

## N4 核心语法

| 语法 | 接续 | 含义 | 例 |
|------|------|------|---|
| 〜たら | 動た形+ら | 如果/当...时 | 雨が降ったら |
| 〜ても | 動て形+も | 即使...也 | 食べても太らない |
| 〜そうだ（様態）| 形容詞語幹+そう | 看起来... | 美味しそう |
| 〜ようにする | 動辞書形+ようにする | 努力做到 | 早く寝るようにする |
| 〜てあげる/もらう/くれる | 動て形+授受 | 给/受 | 教えてもらう |
| 受身形 | 動未然形+れる/られる | 被动 | 褒められた |
| 使役形 | 動未然形+せる/させる | 让/使 | 行かせる |
| 〜ことができる | 動辞書形+ことができる | 能够 | 泳ぐことができる |
