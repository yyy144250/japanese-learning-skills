# 周回顾 (Weekly Review)

## 触发词
复习、回顾、周总结、weekly review、今周、这周学了什么

## 流程

1. **收集数据**：读取 `~/japanese-learning/` 下本周的文件
   - `vocab/daily-vocab-*.md` → 新学词汇
   - `journal/*.md` → 写作练习
   - 其他学习记录

2. **生成周报**：

```
## 📊 本周学习报告（YYYY-MM-DD ~ YYYY-MM-DD）

### 学习天数
X / 7 天 （连续 Y 天）

### 词汇
- 新学：XX 个
- 复习：XX 个
- 覆盖等级：N? 为主
- 主题分布：生活(X)、科技(X)、...

### 语法
- 练习过的语法点：
  1. 〜ている
  2. 〜たら
  ...

### 写作
- 日记 X 篇
- 常见错误类型：助词(X次)、动词变形(X次)...

### 薄弱点分析
1. 【最需要加强】...
2. 【其次】...
3. 【注意】...

### 进步亮点 ✨
- 比上周多学了 X 个词
- 助词错误率从 X% 降到 Y%
- 开始能使用 〜 语法了
```

3. **下周计划建议**：
   - 基于薄弱点推荐侧重模块
   - 设定词汇目标
   - 建议复习的旧内容

4. **综合小测**（10 题）：
   - 覆盖本周所有模块的内容
   - 题型混合（词汇/语法/翻译/填空）

## 无数据时

如果 `~/japanese-learning/` 下没有文件或本周无记录：
- 不要编造数据
- 告诉用户目前没有学习记录
- 建议从今天开始，先做一次 daily-vocab 或 lang-journal
