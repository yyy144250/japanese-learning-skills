# 跟读准备 (Shadowing Prep)

## 触发词
shadowing、跟读、シャドーイング、练口语、朗读

## 流程

1. **确认参数**：
   - 等级
   - 内容类型：日常对话 / 新闻播报 / 动漫台词 / 演讲 / 商务场景
   - 长度：3-5 句（短）/ 6-10 句（中）/ 一段话（长）

2. **生成文本**，标注以下信息：

```
## 跟读材料

### 原文
（完整日文文本）

### 标注版
每句标注：
- 振假名（全文）
- 音高重音：用 ⌝⌜ 标记每个词的 pitch
- 断句标记：用 / 标出自然停顿位置
- 连读标记：用 ⌒ 标出连读/缩约
- 重音标记：用 **粗体** 标出句子重音词

### 逐句解析
1. 原句 → 直译 → 意译
2. 发音难点标注
3. 语调特征说明（升调疑问/降调陈述等）
```

3. **跟读步骤建议**：
   - 第 1 遍：只听，理解大意
   - 第 2 遍：看标注版，小声跟读
   - 第 3 遍：不看文本，跟读
   - 第 4 遍：录音对比

4. **发音难点提取**：列出 3-5 个重点注意的发音现象

## 内容类型特征

- 日常对话：含缩约形（〜てる→てる、〜ている→てる）、终助词多
- 新闻播报：匀速、少缩约、书面表达多
- 动漫台词：语气词多、角色语特征明显
