# 汉字深掘 (Kanji Deep Dive)

## 触发词
汉字、kanji、这个字怎么读、拆解、部首、字源

## 流程

1. **输入**：用户提供 1-5 个汉字
2. **每个汉字输出**：

```
## 〈漢字〉

- **音読み**：（罗马音 + 常见词 2-3 个）
- **訓読み**：（罗马音 + 常见词 2-3 个）
- **部首**：〈部首〉（意义解释）
- **画数**：X 画
- **JLPT**：N?

### 字源故事
（象形/会意/形声的演变过程，配简单描述帮助记忆）

### 组词网络
- 〈漢字〉＋？→ 词1（释义）、词2（释义）、词3（释义）
- ？＋〈漢字〉→ 词4（释义）、词5（释义）、词6（释义）

### 易混字辨析
- 〈漢字A〉 vs 〈漢字B〉：外形差异 + 意义差异 + 记忆技巧

### 书写要点
- 笔顺注意点（如哪一笔容易写错）
- 结构类型（左右/上下/包围）
```

3. **辨析练习**（3 题）：
   - 读音选择
   - 填入正确汉字
   - 根据部首推测含义

## 扩展用法

如果用户给的是一段日文而非单个汉字，自动提取其中的难字进行分析。
