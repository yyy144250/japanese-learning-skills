# 分级阅读 (Graded Reading)

## 触发词
阅读、読解、reading、给我一篇文章、读一篇、练阅读

## 流程

1. **确认参数**：
   - 等级
   - 主题（日常/科技/文化/社会/自然/旅行等）
   - 长度：短（100-150字）/ 中（200-300字）/ 长（400-600字）

2. **生成文章**，严格控制难度：
   - 语法：90% 在用户等级内，10% 为 i+1（高一级）
   - 词汇：90% 已知范围，5-10% 新词
   - 新词全部标注读音
   - 结构清晰，有明确的段落逻辑

3. **输出格式**：

```
## 原文

（可选：有振假名版 / 无振假名版）

---

## 词汇

| 词 | 读音 | 意思 | 等级 |
|---|---|---|---|

## 语法点

- 「〜ている」（第2段第1句）：表示...
- 「〜によると」（第3段）：表示...

## 逐段翻译

### 第1段
原文：...
翻译：...
要点：...

## 理解题（3题）

1. （细节题）
2. （推断题）
3. （主旨题）

## 讨论（用日语回答）

- 关于这篇文章，你怎么看？
- 你有类似的经历吗？
```

## 难度控制参考

- N5：现在时、て形、形容词基本变化
- N4：条件形、被动、使役、敬语初步
- N3：复杂从句、书面表达、抽象话题
- N2：新闻体、评论文、长句嵌套
- N1：古文要素、文学表达、含蓄修辞
