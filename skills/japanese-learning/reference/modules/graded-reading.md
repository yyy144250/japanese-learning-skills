# 分级阅读 (Graded Reading)

## 触发词
阅读、読解、reading、给我一篇文章、读一篇、练阅读

## 流程

1. **读取记忆**：
   - `profile.json` → level、interests、vocab.byLevel（知道大概词汇量）
   - `progress/grammar-progress.json` → mastered 语法列表（文章中可使用的语法范围）
   - `progress/vocab-mastery.jsonl` → struggling 词汇（可融入文章帮助复习）

2. **确认参数**（根据 profile 自动填充，用户可覆盖）：
   - 等级：默认 profile.level
   - 主题：默认从 profile.interests 中选
   - 长度：短（100-150字）/ 中（200-300字）/ 长（400-600字）

3. **生成文章**，严格控制难度：
   - 语法：90% 在 `grammar.mastered` 范围内，10% 为 i+1（grammar.inProgress 或新语法）
   - 词汇：85% 已知范围，10% 从 `vocab.struggling` 中选（间隔复习），5% 全新词
   - 新词全部标注读音
   - 结构清晰，有明确的段落逻辑
   - **话题与 interests 对齐**

4. **输出格式**：

```
## 📖 原文

（根据 level 决定是否标注振假名）

---

## 📝 词汇

| 词 | 读音 | 意思 | 等级 | 备注 |
|---|---|---|---|---|
| ... | ... | ... | N? | 复习词 / 新词 |

## 📚 语法点

- 「〜ている」（第2段第1句）：表示...
- 「〜によると」（第3段）：表示...  ← i+1 新语法

## 🔍 逐段翻译

### 第1段
原文：...
翻译：...
要点：...

## ❓ 理解题（3-5题）

1. （细节题）
2. （推断题）
3. （主旨题）
4. （词汇题：从上下文推测 XX 的含义）
5. （应用题：如果你是文中的人，你会...）

## 💬 讨论（尝试用日语回答）

- 关于这篇文章，你怎么看？
- 你有类似的经历吗？
```

## 难度控制参考

- N5：现在时、て形、形容词基本变化
- N4：条件形、被动、使役、敬语初步
- N3：复杂从句、书面表达、抽象话题
- N2：新闻体、评论文、长句嵌套
- N1：古文要素、文学表达、含蓄修辞

## 会话结束时的记忆更新

- 文章中的新词 → 追加到 `vocab-mastery.jsonl`（status=new）
- 理解题答错涉及的语法 → 在 grammar-progress 中降低该语法信心
- i+1 新语法如果用户理解了 → 追加到 grammar-progress（status=in_progress）
- 如果是第一次完成分级阅读 → milestones.md 记录
- 更新 sessions 摘要
