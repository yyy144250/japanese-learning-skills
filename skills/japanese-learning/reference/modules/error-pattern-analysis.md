# 错误分析 (Error Pattern Analysis)

## 触发词
错误分析、我总是搞错、error pattern、弱点、为什么老犯错

## 流程

1. **收集错误数据**：
   - 从 `~/japanese-learning/journal/` 中的修改记录提取
   - 从用户当前对话中提到的错误
   - 用户可以直接说"我总是搞混 は 和 が"

2. **错误分类**：

```
## 错误模式分析

### 分类统计
| 类别 | 次数 | 占比 | 严重度 |
|------|------|------|--------|
| 助词错误 | X | X% | 高 |
| 动词变形 | X | X% | 中 |
| 敬语误用 | X | X% | 中 |
| 词汇混淆 | X | X% | 低 |
| 语序问题 | X | X% | 低 |
```

3. **Top 3 高频错误详解**：

```
### 错误 #1：〈描述〉

**典型案例**：
- ❌ 你写的：...
- ✅ 正确的：...

**为什么会犯这个错**：
- 母语干扰：中文里...所以你下意识会...
- 规则混淆：...和...看起来像但其实...

**记忆策略**：
- 口诀/联想/对比...

**专项练习**（5 题）：
1. ...
2. ...
```

4. **改善建议**：
   - 针对每个错误模式给出具体的练习建议
   - 推荐对应的模块（如助词错误 → grammar-drill）

## 无数据时

如果没有历史错误记录：
- 让用户随便写几句日语
- 当场分析其中的问题
- 以此为起点建立错误档案
