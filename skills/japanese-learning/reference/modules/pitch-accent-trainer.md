# 音高重音 (Pitch Accent Trainer)

## 触发词
pitch accent、音高、アクセント、这个词怎么读、声调、高低

## 流程

1. **输入**：用户给出单词或句子

2. **标注输出**：

```
## 单词音高分析

### 〈word〉
- 读音：〈hiragana〉
- 音高型：平板型(0) / 头高型(1) / 中高型(2-n) / 尾高型(n+1)
- 音高图示：
  か↑ぞ↓く （头高型：第1拍高，之后下降）
  或用 H/L 标注：L-H-L-L

### 同音异调对比
- 箸（はし）⌝HL = 筷子
- 橋（はし）⌜LH = 桥
- 端（はし）⌜LH⌝ = 边缘（尾高）
```

3. **规则说明**（参考 `reference/data/pitch-accent-rules.md`）：
   - 第 1 拍和第 2 拍必不同高
   - 下降后不再上升（东京方言）
   - 复合词的音高变化规则

4. **句子层面**：
   - 标注助词是否继承前词音高
   - 焦点重音位置
   - 疑问句的语调变化

5. **最小对立组练习**（5 对）：
   - 给出两个同音但不同调的词
   - 让用户判断：这个音高模式对应哪个意思？

## 标注规范

统一使用以下标注系统：
- 数字标注法：0=平板, 1=头高, 2=第2拍后降...
- 图形标注法：⌜(升) ⌝(降) 放在假名间
- 简易标注：H(高) L(低) 放在每个假名上方
