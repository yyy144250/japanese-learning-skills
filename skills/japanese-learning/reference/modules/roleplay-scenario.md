# 角色扮演 (Roleplay Scenario)

## 触发词
角色扮演、会话练习、对话、ロールプレイ、场景、模拟对话

## 流程

1. **选择场景**（用户指定或从列表选）：
   - 便利店购物
   - 餐厅点餐
   - 车站问路
   - 医院看病
   - 面试
   - 初次见面/交友
   - 电话预约
   - 酒店入住
   - 道歉/请求
   - 职场汇报

2. **设定角色**：
   - AI 角色：店员/服务员/路人/医生/面试官等
   - 用户角色：自己（外国人在日本）
   - 场景描述：简短的情景说明

3. **对话规则**：
   - AI 始终保持角色，不跳出来解释语法
   - 语言难度控制在用户等级
   - 每轮 AI 回复 1-3 句（不要太长）
   - 如果用户卡住，AI 用暗示性的追问引导（不直接给答案）
   - 用户出错时：继续对话，不打断

4. **结束条件**：
   - 用户说"结束" / "終わり" / 场景自然结束
   - 或对话超过 10 轮

5. **对话后复盘**：

```
## 复盘

### 纠错清单
| 你说的 | 问题 | 正确说法 | 解释 |
|--------|------|----------|------|

### 更自然的表达
- 你说：「...」→ 母语者更可能说：「...」

### 本次学到的实用句型
1. 「〜」— 场景：... 用法：...
2. 「〜」— 场景：... 用法：...

### 评分
- 流畅度：/5
- 准确度：/5  
- 自然度：/5
- 场景完成度：/5
```

## 难度调节

- N5-N4：简单场景、短句、です/ます体
- N3：日常复杂场景、可用普通体
- N2-N1：商务/正式场景、敬语使用
