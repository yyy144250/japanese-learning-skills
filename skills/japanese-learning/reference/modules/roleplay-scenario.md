# 角色扮演 (Roleplay Scenario)

## 触发词
角色扮演、会话练习、对话、ロールプレイ、场景、模拟对话

## 流程

1. **读取记忆**：
   - `profile.json` → level、interests、grammar.mastered/inProgress
   - `progress/error-archive.json` → 活跃错误（对话中关注这些点）
   - `sessions/YYYY-MM.json` → 之前做过哪些场景（避免重复）

2. **选择场景**（用户指定或根据 interests + level 推荐）：

   **N5-N4 场景**：
   - 便利店购物
   - 餐厅点餐
   - 车站问路
   - 初次见面/自我介绍
   - 超市退换货

   **N3 场景**：
   - 医院看病
   - 电话预约
   - 酒店入住/退房
   - 道歉/请求帮助
   - 快递/投诉

   **N2-N1 场景**：
   - 面试
   - 职场汇报/提案
   - 与房东沟通
   - 银行开户
   - 商务邮件确认电话

   **根据 interests 定制**：
   - anime → 漫画店选购、动漫讨论
   - technology → 手机店询问
   - cooking → 菜市场买菜、和日本朋友分享食谱
   - travel → 观光咨询、温泉入住

3. **设定角色**：
   - AI 角色：店员/服务员/路人/医生/面试官等
   - 用户角色：自己（外国人在日本）
   - 场景描述：简短的情景说明 + 你的任务目标（如"买一杯冰美式"）

4. **对话规则**：
   - AI 始终保持角色，不跳出来解释语法
   - 语言难度控制在 profile.level（但允许出现少量 i+1 表达）
   - 每轮 AI 回复 1-3 句（不要太长）
   - 如果用户卡住，AI 用暗示性的追问引导（不直接给答案）
   - 用户出错时：继续对话，不打断（错误记录下来，最后复盘）
   - **暗中关注 error-archive 中的活跃错误模式**：如果用户在对话中正确避免了旧错误，复盘时特别表扬

5. **结束条件**：
   - 用户说"结束" / "終わり" / 场景自然完成目标
   - 或对话超过 10 轮

6. **对话后复盘**：

```
## 🎭 角色扮演复盘

### 场景完成情况
- 目标：（买到冰美式 / 成功预约 / ...）
- 结果：✅ 完成 / ⚠️ 部分完成 / ❌ 未完成

### 纠错清单
| # | 你说的 | 问题类型 | 正确说法 | 解释 |
|---|--------|---------|----------|------|

### 更自然的表达
- 你说：「...」→ 母语者更可能说：「...」

### 进步观察
- （对比 error-archive，指出改善的地方）
- （指出本次主动使用的高级表达）

### 本次学到的实用句型
1. 「〜」— 场景：... 用法：...
2. 「〜」— 场景：... 用法：...

### 评分
- 流畅度：X/5（能不能撑过去不卡壳）
- 准确度：X/5（语法/词汇正确率）
- 自然度：X/5（像不像日本人会说的话）
- 任务完成度：X/5（达成沟通目标了吗）
- 总分：XX/20
```

## 难度调节

根据 profile.level 自动调节：
- N5-N4：简单场景、短句、です/ます体、对方会说慢一点
- N3：日常复杂场景、可用普通体、对方语速正常
- N2-N1：商务/正式场景、敬语使用、对方用方言/缩略语

## 会话结束时的记忆更新

本模块结束后，需要更新：
- `sessions/YYYY-MM.json`: 记录场景名称、评分
- `progress/error-archive.json`:
  - 对话中的错误 → 匹配现有模式则 occurrences += 1
  - 如果旧错误在本次对话中没出现 → 不操作（保持现状）
- `profile.json`:
  - 如果是第一次角色扮演 → milestones.md 记录
  - 如果总分 >= 18/20 → milestones.md 记录"完美完成 XX 场景"
- `progress/vocab-mastery.jsonl`:
  - "本次学到的实用句型"中的新词 → 追加为 new
