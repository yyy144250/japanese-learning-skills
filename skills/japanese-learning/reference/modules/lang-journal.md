# 日语日记 (Language Journal)

## 触发词
日记、日本語日記、journal、今天发生了...、帮我改日语

## 流程

1. **读取记忆**：
   - `profile.json` → level、streak、grammar.mastered（知道用户会什么语法）
   - `progress/error-archive.json` → 活跃错误模式（关注这些方面的进步/退步）
   - `~/japanese-learning/journal/` → 检查是否有近期日记（用于对比进步）

2. **输入**：用户用日语写一段话
   - 可以夹杂中文/英文（AI 帮转为日语）
   - 可以写得很短（3-5 句也行）
   - 内容不限：今天做了什么、感想、对某事的看法
   - 如果用户不知道写什么 → 根据 interests 给 3 个话题建议

3. **三档修改输出**：

```
## 原文
（用户写的）

## 修正版（只改错误）
（仅修正语法/拼写错误，保持原文风格和用词水平）
修改处用 **粗体** 标出

## 自然版（母语者的说法）
（改成日本人日常会说/写的方式，可能换词、调整语序）

## 进阶版（用更高级的表达）
（使用比用户当前水平高一级的词汇和语法改写）
新引入的表达用 **粗体** 标出
```

4. **逐条修改说明**：

```
### 修改详解

| # | 原文 | 修改为 | 类型 | 原因 |
|---|------|--------|------|------|
| 1 | ... | ... | 助词 | に表示目的地，不用で |
| 2 | ... | ... | 词汇 | 「面白い」比「楽しい」更适合这个语境 |
```

5. **与错误档案对照**：
   - 检查本次日记中的错误是否与 `error-archive.json` 中的活跃模式匹配
   - 如果某个老错误没有出现 → "🎉 之前常犯的「XX」错误这次没出现了！"
   - 如果某个老错误又出现了 → 温和提醒，给出记忆技巧

6. **进步对比**（如果有历史日记）：
   - 与 7 天前或最近一篇日记对比
   - 指出具体进步："这次主动用了受身形，上次还不敢用"
   - 字数趋势、语法复杂度趋势

7. **值得记住的表达**：从自然版/进阶版中提取 2-3 个好用的表达

8. **保存**：`~/japanese-learning/journal/YYYY-MM-DD.md`

## 鼓励机制

- 如果 streak > 3 且有连续日记记录 → 表扬坚持
- 对比前次日记，**一定要先指出进步**
- 绝不只挑毛病，先肯定做得好的部分
- 如果用户主动用了 grammar.mastered 中的高级语法 → 特别表扬

## 会话结束时的记忆更新

本模块结束后，需要更新：
- `profile.json`:
  - `monthly.YYYY-MM.journalEntries += 1`
- `progress/error-archive.json`:
  - 本次日记中的错误 → 匹配现有模式则 occurrences += 1
  - 新错误模式 → 创建新条目
  - 之前的活跃错误本次未出现 → 不做操作（需要连续多次不出现才算 resolved）
- `progress/vocab-mastery.jsonl`:
  - 进阶版中的新表达 → 如果用户表示想学，追加为 new
- 如果是用户的第一篇日记 → 写入 milestones.md："✍️ 写出第一篇日语日记"
- 如果日记字数创新高 → 写入 milestones.md
