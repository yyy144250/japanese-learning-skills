# 日语日记 (Language Journal)

## 触发词
日记、日本語日記、journal、今天发生了...、帮我改日语

## 流程

1. **输入**：用户用日语写一段话
   - 可以夹杂中文/英文（AI 帮转为日语）
   - 可以写得很短（3-5 句也行）
   - 内容不限：今天做了什么、感想、对某事的看法

2. **三档修改输出**：

```
## 原文
（用户写的）

## 修正版（只改错误）
（仅修正语法/拼写错误，保持原文风格和用词水平）

## 自然版（母语者的说法）
（改成日本人日常会说/写的方式，可能换词、调整语序）

## 进阶版（用更高级的表达）
（使用比用户当前水平高一级的词汇和语法改写）
```

3. **逐条修改说明**：

```
### 修改详解

| # | 原文 | 修改为 | 类型 | 原因 |
|---|------|--------|------|------|
| 1 | ... | ... | 助词 | に表示目的地，不用で |
| 2 | ... | ... | 词汇 | 「面白い」比「楽しい」更适合这个语境 |
```

4. **值得记住的表达**：从自然版/进阶版中提取 2-3 个好用的表达

5. **保存建议**：`~/japanese-learning/journal/YYYY-MM-DD.md`

## 鼓励机制

- 如果用户连续写日记（检查历史文件），表扬坚持
- 对比上次的日记，指出进步的地方
- 绝不只挑毛病，先肯定做得好的部分
