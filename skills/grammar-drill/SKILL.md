# Grammar Drill (文法ドリル)

Targeted grammar practice with clear explanations, pattern recognition, and progressive exercises.

## Ask First

1. Which grammar point? (specific pattern, or "pick one for my level")
   - If unspecified: select a common point for their level
2. JLPT level?
   - Default: N4
3. Focus area? (understanding / production / both)
   - Default: both
4. Save location?
   - Default: `~/japanese-learning/grammar/`

## Grammar Explanation Structure

```markdown
# [Grammar Point] — [Pattern in Japanese]

## Quick Reference
- **Pattern:** Verb/Adj/Noun + [form] + [particle/ending]
- **Meaning:** English equivalent
- **Level:** JLPT N4
- **Formality:** casual / neutral / formal
- **Function:** [expressing reason / contrast / desire / etc.]

## Formation Rules

| Word type | How to connect | Example |
|-----------|---------------|---------|
| Verb (dictionary) | → [transformation] | 食べる → 食べ... |
| Verb (ます stem) | → [transformation] | 食べます → 食べ... |
| い-adjective | → [transformation] | 高い → 高... |
| な-adjective | → [transformation] | 静か → 静か... |
| Noun | → [transformation] | 学生 → 学生... |

## Core Meaning & Nuance

Explain in simple terms:
- What feeling/meaning does this pattern convey?
- When would a Japanese person choose this over alternatives?
- What's the "mental image" behind this grammar?
```
